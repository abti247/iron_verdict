# Stream overlay in OBS

The step-by-step guide for adding the stream overlay to OBS lives in the app, in German and English: on role select of the session, click the **?** beside **Stream overlay (OBS)**. It covers copying the URL, adding the browser source, arranging the overlay (directly in OBS or with a layout code in the URL), what shows in the stream while editing, the VPortal login and a checklist before going live.

The display settings panel (gear or **S**) has its own **?** that explains the panel: break, layout editor, layout code and contrast mode.

*Why in the app:* the text is where the question comes up, and it is maintained in one place (`help.obs` and `help.display` in `src/iron_verdict/static/locales/*.json`). Technical details of the overlay: [architecture.md](architecture.md), *Stream overlay*.
